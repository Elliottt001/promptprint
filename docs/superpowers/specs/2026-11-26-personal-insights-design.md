# 语言星云：个人回顾与关注分析需求设计

日期：2026-11-26

状态：用户已于 2026-11-26 确认整体设计，包括下文建议的默认值；本文是本轮实现合同。尚未进入实现。

## 1. 目标和本轮范围

让用户基于本机 AI 对话记录查看个人回顾、关注变化、活跃日历和产品使用差异，并整理词语、导出分享图片。

本轮包含六项功能：

1. 自然年／自然月回顾。
2. 任意两个日期区间的关注变化比较。
3. 日级活跃热力图。
4. 产品代表词、共同词、独有词和手动用途标签。
5. 三种尺寸的分享卡片与 PNG 导出。
6. 隐藏词、别名合并、设置自动保存与导出／导入。

本轮完成统计逻辑、可操作入口、基础预览和导出，使功能可以实际验证。沿用现有样式；整体视觉、页面重排、动效和分享模板的精细设计由用户下一轮处理。

在线演示、GitHub 发布、更多客户端适配、词云形状和新配色均不属于本轮。

## 2. 用户已确认的决定

- 以上六项功能全部纳入本轮，先做功能，前端设计下一次再改。
- 隐藏词和别名合并统一影响所有词语统计与导出，包括回顾、关注变化、产品对比、词云和词语详情。
- 消息数、活跃天数和连续活跃天数按原始去重消息计算，不受词语规则影响。
- 关注变化允许任意两个日期区间，并提供常用周期快捷选项。
- 隐藏词、别名和产品用途标签自动保存，并支持只包含个人设置的文件导出／导入。

下文原先建议的默认值已随整体设计一起确认，实现时按本文执行。

## 3. 方案选择

### A. 浏览器复用现有聚合数据（推荐）

Python 继续输出日期／产品聚合；浏览器统一应用个人词语规则，再计算六项功能。个人设置在浏览器保存。无需新增网络服务、模型 API 或原始正文数据。

优点：沿用现有架构，规则修改即时生效，功能共享同一统计口径。限制：自动保存属于同一浏览器的同一本地站点地址；更换浏览器、电脑或本地端口时用设置导出／导入迁移。

### B. Python 预生成全部回顾和分析

优点：浏览器计算较少。代价：修改规则或日期需要重新生成，任意区间与交互整理不方便，容易重复统计逻辑。

### C. 增加本地 API 保存设置并计算分析

优点：设置可以跨本地端口使用。代价：增加服务接口、写入协议和维护工作。

本轮建议采用 A；现有默认端口保持不变，端口被占用时仍沿用空闲端口回退，设置迁移能力覆盖地址改变的情况。

## 4. 共享数据与统计口径

### 4.1 数据范围

- 源文件只读，只统计现有适配器可靠识别的用户消息。
- 不增加 AI 回复、原始对话正文、用户画像模型或网络上传。
- 复用完整的日／产品词频 buckets，不用全局 Top 600 作为分析输入。
- 继续按快照时区解释日期，不使用浏览器时区重新划分消息。
- 日期未知的消息只进入“全部时间”的词语和产品统计，不进入日期区间、回顾或热力图。
- 消息数是去重后的消息数量，不是词出现次数。

### 4.2 规则与筛选顺序

1. 选择产品和时间范围，读取对应原始聚合桶。
2. 根据别名组把原始词映射到统一代表词，并相加频次、来源与日期统计。
3. 应用个人隐藏规则。
4. 主题提纯模式额外按代表词精确匹配系统停用词；原始模式保留系统泛词。
5. 从完整有效词表计算分析。
6. 搜索和 Top 数量只截取词云展示，不改变回顾、比较或产品分析。

别名与隐藏都适用于原始／提纯两种模式。“原始”表示保留泛词，不表示忽略个人规则。合并前后消息数量不变，合并本身不丢失词次数。

### 4.3 词频占比

有效词总次数是应用上述个人规则及统计模式之后所有词的出现次数之和。

词频占比 = 某词出现次数 / 当前范围有效词总次数。

比较展示次数、占比和占比差值，差值使用百分点。总次数为 0 时不做除法，返回无有效词状态。隐藏或修改别名后，分子和分母按统一规则重算。

### 4.4 时间与覆盖

- 用户选择的起止日期均包含当天；内部可以使用结束日期下一天作为排他上界。
- 日期非法或起点晚于终点时阻止计算，保留上一次有效结果并给出原因。
- 区间可以重叠；快捷选项使用自然日历边界，周从周一开始。
- 未来日期不伪造记录；尚未结束的月／年标为“截至快照日期”。
- 回顾显示请求周期和实际有记录的日期跨度。
- 空白日期只能解释为“未读取到消息”；不能证明用户当天没有使用 AI。
- 以快照生成时间对应的本地日期作为数据截止日，未来热力图格子不可计作无活动。

## 5. 功能需求

### 5.1 年度／月度回顾

选择自然年或自然月，并选择产品。默认使用快照最新日期所在月，提供切换到年的入口；沿用当前统计模式。

回顾内容：消息总数、活跃天数、最长连续活跃天数、最活跃日期、Top 5 词、各产品消息分布、周期词云，以及相对上一自然周期的代表性变化。

最活跃日期并列时列出全部日期及共同数量，不随意选一个。连续活跃按相邻自然日有消息计算，只在所选周期内计算。

回顾文案使用有依据的固定模板，如“本月最常出现的词是……”。不推断职业、人格或聊天用途。比较不足时省略变化文案并显示原因。

零消息时显示空状态，不生成虚构总结。消息存在但全部词被过滤时保留活跃和来源统计，词语部分显示无有效词。

回顾按模块组织，提供基础可操作展示；翻页动效和精细故事卡设计留到下一轮。

### 5.2 关注变化

设置基准区间 A 和观察区间 B；提供“本周／上周、本月／上月、本年／上年”快捷选项。两个区间共用相同产品、模式和个人规则。

建议默认最低门槛：两个区间各至少 5 条消息；候选词至少在一边出现 3 次。门槛集中为内部常量，本轮不新增高级配置界面。

分类：

- 新出现：A 次数为 0，B 次数至少 3。
- 消失：B 次数为 0，A 次数至少 3。
- 升温：两边均出现，占比 B > A，且至少一边次数达到 3。
- 降温：两边均出现，占比 B < A，且至少一边次数达到 3。
- 占比相同的词不进入变化列表。

每类最多显示 10 个词；按对应占比差值的绝对值降序，再按较大次数降序，最后按词名稳定排序。

每个词显示两边次数、占比和百分点变化。任一区间少于 5 条消息时展示基础数量与样本较少状态，不生成排行榜；任一边有效词总次数为 0 时也不生成排行榜。无符合门槛的词时显示没有明显变化。

### 5.3 活跃热力图

选择一个自然年，默认最新记录所在年；按当前产品筛选统计每日去重消息数。使用周一开始的日历布局，格子显示日期与数量。

颜色规则保持固定、可解释：0 条、1–4 条、5–9 条、10–19 条、20 条及以上。未来日期单独表示，尚未到来的日期不能点击切换到记录。

点击或键盘激活日期后，现有词云切到该日，保留产品、模式和个人规则；允许点击零记录日期查看空状态。

展示该年消息数、活跃天数、最长连续活跃天数及最活跃日期。指标来自消息，不受隐藏、合并、搜索或 Top 数量影响。提供可读标签和键盘操作。

### 5.4 产品使用差异

使用当前所选产品与时间范围，展示各产品消息数、词频概况、代表词、共同词、独有词，以及用户填写的用途标签。

用途标签是用户手写文本，不自动从词语推断，默认空；为空时不展示虚构用途。标签保存到个人设置中，产品名仍是统计身份，标签不会改变归属。

建议默认：有至少 5 条消息且有有效词的产品参与代表词及共同／独有比较；其他产品显示自己的基础统计并提示数据不足。只有一个符合条件的产品时展示其 Top 词，不称为跨产品代表或独有。

多产品比较规则：

- 候选词在目标产品至少出现 3 次。
- 目标产品词占比与其他参与产品合计词占比相减，正差值用于代表词排名。
- 代表词最多 5 个，按差值、目标次数和词名稳定排序。
- 共同词要求在每个参与比较的产品中均至少出现 3 次。
- 独有词要求仅在一个参与产品出现且至少 3 次，其他参与产品为 0。
- 共同／独有列表最多各 10 个，以总次数降序，再按词名排序。
- 使用“当前所选产品中的共同／独有词”文案，不声称覆盖未读取到的产品历史。

### 5.5 分享卡片

支持正方形 1080×1080、手机竖版 1080×1920、横版 1600×1000，输出 PNG。

选择当前范围词云或年度／月度回顾作为卡片内容；自定义标题默认“我的 AI 足迹”，最多 80 个字符；提供时间范围、消息数、Top 词、来源信息的显示开关。

卡片应用当前产品、模式和个人词语规则；词云卡片同时遵循当前搜索和 Top 展示选择。回顾卡片使用完整回顾口径，界面说明当前选择的内容类型。

来源信息默认关闭；可主动显示产品名称和消息数或手动标签。任何模板均不得包含本机路径、会话 ID、原始正文或适配器诊断。

提供与导出一致的基础预览和下载入口；预览与下载共用同一内容和绘制逻辑。不同长宽比重新布局词云，不拉伸已有布局；过长标题换行，内容不得越出边界。

隐藏词不会出现在卡片中。没有可分享内容时禁用导出并说明原因；消息存在但没有有效词时仍允许导出活跃回顾。导出失败保留页面状态并提示重试。

本轮使用现有视觉元素和一套基础模板，不把精细美术设计作为功能验收前提。

### 5.6 个人词语与产品设置

隐藏词：提供词语详情中的隐藏入口、可查看的隐藏列表、逐项恢复及全部恢复。

别名：用户创建由代表词和成员词组成的组，代表词也作为成员纳入组，组内至少包含两个不同成员。成员可使用当前有效词表之外的拼写，供未来快照复用。字符串去首尾空白、统一 Unicode NFKC 和英文大小写；组成员直接映射到代表词，不采用链式规则。

同一成员不能属于多个组；代表词也不能与其他组成员冲突；拒绝空值及冲突配置并保留原设置。编辑和解除组时从原始聚合词表重新计算，不反复加工已合并结果。

隐藏组记录所有成员；一个组任一成员在隐藏名单中时整个组隐藏。解除合并后原成员继续保持隐藏，避免隐藏词意外重新出现；恢复整个组会清除其成员的隐藏标记。

自动保存：每次有效修改后保存到当前浏览器的本地站点，页面刷新后恢复。不保存聊天正文或个人统计到设置文件。浏览器禁止存储或空间不足时本次操作在内存生效，提示尚未保存，并仍可导出。

导出：版本化 JSON，包含 hiddenWords、aliasGroups 和 productLabels；不包含快照、路径、消息、词频、浏览器身份、临时产品筛选和时间筛选。

导入：验证版本、结构、字符串和别名冲突，成功后整体替换个人设置并立即重算，提供撤销本次导入；无效文件拒绝导入，现有设置保持不变。不支持的版本提示原因。

恢复默认：清空隐藏、别名和手动产品标签，系统停用词与源数据不变；提供撤销最近一次设置操作。撤销范围只包含个人设置修改，不包含日历导航。

所有用户文本以文本方式渲染，不能作为 HTML 或执行内容。重扫后保留个人规则，词暂时不存在时不删除规则。导入其他机器的产品标签时允许保留当前目录尚未出现的产品名，便于迁移。

## 6. 模块边界与实现方向

- Python 继续负责只读扫描和原始日级聚合；这六项功能原则上不要求修改适配器或新增正文输出。
- 共享统计模块接收快照、日期范围、产品和词语设置，输出统一有效词表、日级数量与来源统计。
- 回顾、周期比较、活跃指标和产品分析由纯函数计算，便于直接验证，界面与导出消费同一结果。
- 设置模块负责规范化、校验、自动保存、迁移和撤销；统计模块不承担浏览器存储。
- 分享绘制模块负责布局与输出；基础预览复用导出的绘制路径。
- 沿用已有页面组件和测试工具，不引入前端框架或新的运行依赖。
- 后续实现计划按共享规则、分析功能、交互与分享分阶段组织；使用单代理顺序执行，不授权委派。

## 7. 验收标准

### 7.1 统一规则

- 合并两个词后，所有功能中的合并次数等于原词次数之和，来源和日期频次对应相加。
- 隐藏词组后，回顾、比较、产品列表、词云、详情和分享都不出现该组。
- 隐藏、合并、恢复与撤销均不改变消息数和日级活跃指标。
- 修改规则不会更改原始快照；重复修改和恢复没有累计误差。
- 切换模式时系统停用词差异正确，个人规则始终生效；搜索与 Top 不改变分析输入。

### 7.2 回顾与日期

- 验证月末、闰日、跨年周、结束日期包含当天和快照截止日。
- 验证并列最活跃日期、断开的连续记录、全空、全部词隐藏和日期未知。
- 回顾与对应周期的消息、来源和 Top 词统计一致。

### 7.3 关注变化

- 词频次数不同但占比相同的词不误报升温。
- 新出现／消失、低频门槛、样本不足和零分母返回正确分类或状态。
- 任意区间、重叠区间和快捷区间的选择正确；两边统一应用规则。

### 7.4 热力图和产品

- 热力图每日数量与桶消息数一致；零记录与未来日期区分正确。
- 点击／键盘激活日期切换词云，产品选择保持不变。
- 构造不同产品消息量样本，确认代表词使用相对占比而非单纯总次数。
- 产品数据不足、单产品、共同词和所选范围独有词的状态与门槛正确。

### 7.5 设置与分享

- 同一站点刷新能恢复个人设置；导出文件不包含词频、消息或路径。
- 有效导入、无效版本、冲突别名、撤销、浏览器存储失败和新快照复用行为正确。
- 三种 PNG 尺寸正确，内容与预览一致，隐藏规则生效，长标题和窄屏入口可用。
- 默认分享图片不含来源信息；任何开关组合均不暴露路径或原始正文。

### 7.6 回归与交付

- 保留现有启动、扫描、两种模式、来源筛选、日历切换和普通词云功能。
- 运行已有 Python／Node 测试，并为共享规则、各分析函数和关键浏览器操作增加必要测试。
- 更新 README 的功能和统计口径说明；如重建便携包，包内继续使用空快照并包含新增运行文件。
- 只根据实际运行报告验证结果；Windows／Linux 实机验证边界沿用现有说明。
